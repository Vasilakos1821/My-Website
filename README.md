## API section:
This section is my favorite and it integrates APIs directly into the interface using JS, featuring interactive cards styled to blend into the cosmic theme:

* **International Space Station Tracker:** Pulls live orbital coordinates (latitude and longitude) from the *Where The ISS At* API to track the station's real-time position over Earth.
* **Global City Weather:** Takes user-entered city input, resolves geographic coordinates via Open-Meteo's Geocoding API, and fetches live atmospheric temperatures and day/night sky status.
* **Programming & General Humor:** Fetches safe, dynamic jokes via JokeAPI with punchline-reveal handling.
* **Cosmic Kitty:** Calls *TheCatAPI* to dynamically fetch and display random feline pictures with built-in asynchronous image load handling.
